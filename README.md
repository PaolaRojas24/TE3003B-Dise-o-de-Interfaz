# TE3003B Diseño de Interfaz

## Requerimientos

- Manipulación del robot en un espacio tridimensional con flechas o por coordenadas. En caso de ser por coordenadas, deberá evaluar una trayectoria sin colisiones con el mismo robot.
- Dibujar sobre una hoja de papel una de las siguientes tres figuras:
- - cuadrado de 5 cm de lado
- - triangulo equilátero de 5 cm de lado
- - circulo de 5 cm de diámetro
- Dibujar un patrón a partir del código g. El usuario entrega la trayectoria del archivo y el robot genera el trazo señalado
- Reconocimiento de figuras a través de cámara. El usuario imprime sobre una hoja de papel un cuadrado, un circulo y un triangulo. El robot debe posicionarse sobre el triangulo, el cuadrado y el circulo, siempre en esta secuencia, incluso cuando la ubicación de los elementos se cambia en una prueba con un patrón diferente
